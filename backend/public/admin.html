AnimeDelta Admin

Status

Live counts from the API. Requires a valid admin token.

Add a series to the animelist

Creates (or updates, if the title matches) a series with its episode list. Each episode URL becomes that episode's video source — only link media you own or are allowed to use (your own files/CDN, or a YouTube video the channel allows to be embedded).

Attach a source to an existing episode

Find a series already in the list, pick an episode, then add a video source and/or subtitle track to it.
